# Editing your site (no code needed)

Everything below is done in the Shopify admin.

## Change pictures, text, and sections

1. Go to **Online Store → Themes → Customize**.
2. Pick the page to edit from the drop-down at the top (Home page, Products, Pages → About, and so on).
3. Click any section on the left to change its pictures, text, buttons, and layout.
4. **Add section** adds a new one. Drag the handles to reorder, and click the eye icon to hide.
5. Click **Save**. Changes go live immediately.

### Sections you can add

| Section | Use it for |
|---|---|
| **Large image banner** | Full-width hero photo with heading and buttons |
| **Featured prints** | A grid of prints from any collection |
| **Collections** | Tiles linking to collections (Landscapes, Wildlife, …) |
| **Photo gallery** | A wall of photos. Upload any images, and optionally link each to a print |
| **Image with text** | Photo beside a story (great for About) |
| **Text** | Headings, paragraphs, and buttons |
| **Latest blog posts** | Your newest journal entries |
| **Contact form** | Messages go to your store email |

## Add a new print for sale

Create the product in your print vendor app (Prodigi or Lumaprints) and sync it to Shopify. To feature it, add it to a collection. It then appears on the site automatically. Size, frame, and mat choices show up as buttons, with a live frame preview.

Option names should be **Frame** and **Mat** for the preview to work. You can change these names in Customize → Products → Product page.

## Edit the About page

**Online Store → Pages → About.** The written text is edited there. For the photos and side-by-side story sections, use Customize → Pages → About.

## Write a blog post

**Content → Blog posts → Add blog post.** Add a featured image so it looks good on the homepage.

## Change menus

**Online Store → Navigation → Main menu** (header) or **Footer menu**.

## Change fonts, colors, logo, and social links

**Customize → Theme settings** (the gear icon at the bottom left).

## See analytics

**Analytics** in the left menu: visitors, top pages, traffic sources, best sellers, and conversion rate.
